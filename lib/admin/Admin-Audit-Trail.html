Audit Log Data Model

Firestore collection and equivalent real-time node structure for activity logging

Firestore Collection

auditLogs/{autoId}
  • timestamp: serverTimestamp()
  • userId: authenticated user UID
  • userName: display name of the actor
  • action: login, logout, profile_edit, report_export, incident_update, camera_config
  • targetType: profile, report, incident, camera, system
  • targetId: affected document or asset ID
  • details: human-readable summary of the change
  • status: success, review, failed, recorded

Realtime Database Node

/auditLogs/{pushId}
  • timestamp: ISO string or epoch millis
  • userId: actor UID
  • userName: actor display name
  • action: normalized event type
  • details: action summary plus target reference
  • status: event outcome
Recommended write pattern: append-only log entries with immutable timestamps to keep the trail tamper-resistant.
